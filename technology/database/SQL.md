# 🟠 Oracle Database Tutorial

Oracle is enterprise-focused and uses **SQL + PL/SQL**.

---

## 1️⃣ Connect to Oracle

```bash
sqlplus username/password@localhost:1521/XEPDB1
```

---

## 2️⃣ Create Table

```sql
CREATE TABLE employees (
    id NUMBER GENERATED BY DEFAULT AS IDENTITY,
    name VARCHAR2(100),
    salary NUMBER(10,2),
    hire_date DATE DEFAULT SYSDATE,
    PRIMARY KEY (id)
);
```

**Common Oracle Data Types**

* `NUMBER`
* `VARCHAR2`
* `DATE`
* `TIMESTAMP`
* `CLOB`
* `BLOB`

---

## 3️⃣ Insert Data

```sql
INSERT INTO employees (name, salary)
VALUES ('John', 50000);
```

---

## 4️⃣ Query Data

```sql
SELECT * FROM employees;

SELECT name, salary
FROM employees
WHERE salary > 40000
ORDER BY salary DESC
FETCH FIRST 5 ROWS ONLY;
```

---

## 5️⃣ Update

```sql
UPDATE employees
SET salary = salary * 1.1
WHERE id = 1;
```

---

## 6️⃣ Delete

```sql
DELETE FROM employees
WHERE id = 1;
```

---

## 7️⃣ Joins

```sql
SELECT e.name, d.department_name
FROM employees e
JOIN departments d
ON e.department_id = d.id;
```

---

## 8️⃣ Index

```sql
CREATE INDEX idx_salary
ON employees(salary);
```

---

## 9️⃣ View

```sql
CREATE VIEW high_paid AS
SELECT * FROM employees
WHERE salary > 70000;
```

---

## 🔟 PL/SQL Block (Oracle Unique)

```sql
BEGIN
   UPDATE employees
   SET salary = salary + 1000;
END;
/
```

Oracle supports:

* Stored procedures
* Packages
* Triggers
* Sequences (though IDENTITY is modern standard)

---

## Common Oracle Commands

| Command            | Purpose          |
| ------------------ | ---------------- |
| `DESC table_name;` | Describe table   |
| `SET LINESIZE 200` | Format output    |
| `COMMIT;`          | Save transaction |
| `ROLLBACK;`        | Undo transaction |
| `EXPLAIN PLAN FOR` | Execution plan   |
| `SHOW USER;`       | Current user     |

# 🟡 MySQL Tutorial

MySQL is widely used for web applications.

---

## 1️⃣ Connect

```bash
mysql -u root -p
```

---

## 2️⃣ Create Database

```sql
CREATE DATABASE company;
USE company;
```

---

## 3️⃣ Create Table

```sql
CREATE TABLE employees (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100),
    salary DECIMAL(10,2),
    hire_date TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

**Common Data Types**

* `INT`
* `VARCHAR`
* `TEXT`
* `DECIMAL`
* `DATETIME`
* `JSON`

---

## 4️⃣ Insert

```sql
INSERT INTO employees (name, salary)
VALUES ('Alice', 60000);
```

---

## 5️⃣ Select

```sql
SELECT * FROM employees;

SELECT name, salary
FROM employees
WHERE salary > 50000
ORDER BY salary DESC
LIMIT 5;
```

---

## 6️⃣ Update

```sql
UPDATE employees
SET salary = salary + 2000
WHERE id = 1;
```

---

## 7️⃣ Delete

```sql
DELETE FROM employees
WHERE id = 1;
```

---

## 8️⃣ Index

```sql
CREATE INDEX idx_salary
ON employees(salary);
```

---

## 9️⃣ Stored Procedure

```sql
DELIMITER //

CREATE PROCEDURE give_raise()

  UPDATE employees
  SET salary = salary + 1000;
END //

DELIMITER ;
```

---

## Common MySQL Commands

# 🟢 PostgreSQL Tutorial

Postgres is known for standards compliance and advanced features.

---

## 1️⃣ Connect

```bash
psql -U postgres
```

---

## 2️⃣ Create Database

```sql
CREATE DATABASE company;
\c company
```

---

## 3️⃣ Create Table

```sql
CREATE TABLE employees (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100),
    salary NUMERIC(10,2),
    hire_date TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

**Common Data Types**

* `SERIAL` / `IDENTITY`
* `NUMERIC`
* `TEXT`
* `BOOLEAN`
* `UUID`
* `JSONB`

---

## 4️⃣ Insert

```sql
INSERT INTO employees (name, salary)
VALUES ('David', 55000)
RETURNING *;
```

---

## 5️⃣ Select

```sql
SELECT *
FROM employees
WHERE salary > 50000
ORDER BY salary DESC
LIMIT 5;
```

---

## 6️⃣ Update

```sql
UPDATE employees
SET salary = salary * 1.05
WHERE id = 1
RETURNING OLD.salary, NEW.salary;
```

---

## 7️⃣ Delete

```sql
DELETE FROM employees
WHERE id = 1
RETURNING *;
```

---

## 8️⃣ Index

```sql
CREATE INDEX idx_salary
ON employees(salary);
```

---

## 9️⃣ Function

```sql
CREATE FUNCTION give_raise()
RETURNS VOID AS $$
BEGIN
   UPDATE employees
   SET salary = salary + 1000;
END;
$$ LANGUAGE plpgsql;
```

---

## Common PostgreSQL Commands

| Command           | Purpose        |
| ----------------- | -------------- |
| `\l`              | List databases |
| `\dt`             | List tables    |
| `\d table`        | Describe table |
| `EXPLAIN ANALYZE` | Execution plan |
| `VACUUM`          | Cleanup        |
| `ANALYZE`         | Update stats   |
| `COMMIT`          | Save           |
| `ROLLBACK`        | Undo           |

# ⚖️ Quick Comparison

| Feature           | Oracle    | MySQL   | PostgreSQL          |
| ----------------- | --------- | ------- | ------------------- |
| Identity Column   | ✅         | ✅       | ✅                   |
| RETURNING Clause  | Limited   | Limited | Advanced            |
| JSON Support      | Strong    | Good    | Very Strong (JSONB) |
| Stored Procedures | PL/SQL    | Yes     | PL/pgSQL            |
| CLI Tool          | sqlplus   | mysql   | psql                |
| Enterprise Scale  | Very High | Medium  | Very High           |
